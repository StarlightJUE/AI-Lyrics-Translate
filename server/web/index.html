元提示词 (Meta Prompt) 可编辑系统框架 · 行数与防泄漏约束
负责严格 1:1 行数对应、纯净格式输出、原文语言保护，以及严禁在输出中包含背景信息的核心纪律。
用户提示词 (User Prompt) 文学审美调优 · 实时生效
系统请求时会自动将【元提示词】与【用户提示词】拼接传给大模型。此处直接回显当前生效的提示词，修改后点击保存立即写入配置文件生效。
服务与管理端口配置
